### 🌟 CÁCH 1: Thao tác trực tiếp trên Website (Khuyên dùng)
1. Mở trang web tuyển dụng, cuộn xuống chân trang bấm: **`🔒 Tự Sửa Bài Tuyển Dụng`** (hoặc nhấn phím tắt **`Ctrl + Shift + A`**).
2. Nhập mã PIN bảo mật: **`6868`**.
3. Trong bảng quản lý:
   - Sửa nội dung các vị trí hiện có (Tiêu đề, Lương, Ca làm, Cơm trưa, Yêu cầu...).
   - Bấm **`➕ Thêm Vị Trí Mới`** để tạo thêm 1 công việc khác cho dự án mới.
   - Bấm **`🗑️ Xóa vị trí này`** nếu công việc đó đã tuyển đủ người.
4. Bấm **`👁️ Xem Thử Ngay`** để kiểm tra giao diện trực quan.
5. Bấm **`📥 Tải File job-config.js Mới`** -> File sẽ được tải về thư mục `Downloads`.
6. Chép đè file vừa tải vào thư mục này (`D:\videos\landing_page\`).
7. Nhấp đúp chạy file **`1_Cap_Nhat_Len_Mang.bat`** -> Sau 30 giây toàn bộ trang web trên mạng sẽ tự động cập nhật!

### 📝 CÁCH 2: Mở file `job-config.js` bằng Notepad
1. Mở file **`job-config.js`** bằng Notepad.
2. Bạn sẽ thấy mảng `jobs: [ ... ]`. Mỗi công việc nằm trong một cặp dấu ngoặc nhọn `{ ... }`.
3. Bạn có thể copy thêm 1 khối `{ ... }` mới hoặc sửa chữ trực tiếp trong các dấu ngoặc kép `""`.
4. Bấm **Ctrl + S** để lưu lại $\rightarrow$ Nhấp đúp file **`1_Cap_Nhat_Len_Mang.bat`** là xong!
